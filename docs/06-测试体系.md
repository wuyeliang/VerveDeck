## 2. 运行方式

测试运行在 **backend 容器内**（pytest 直连 127.0.0.1:3001，与生产同环境）：

```bash
# 同步测试文件进容器（镜像重建后必做）
docker exec fintune-backend-1 mkdir -p /app/tests
docker cp /opt/vervedeck/platform/backend/tests/. fintune-backend-1:/app/tests/

# 快速套件（13 文件，不含 e2e）
docker exec fintune-backend-1 sh -c \
  "cd /app/tests && python -m pytest test_unit_core.py test_unit_dataset.py test_api_auth.py \
   test_api_rbac.py test_api_admin.py test_api_datasets.py test_api_models.py \
   test_api_training.py test_api_evals.py test_api_inference.py test_api_deploy_lifecycle.py \
   test_api_cluster_dashboard.py test_api_storage.py -v --tb=short -p no:cacheprovider"

# E2E（真实 GPU，需无任务占用；约 14 分钟）
docker exec fintune-backend-1 sh -c \
  "cd /app/tests && python -m pytest test_e2e.py -v --tb=short -p no:cacheprovider"
```

## 3. 关键约定（踩坑沉淀）

1. **实体唯一后缀 `SUF`**（uuid hex6）：所有测试实体带后缀，套件可重复运行互不干扰；
2. **GPU 常驻部署占用**：默认项目有常驻推理部署（占 1 GPU），故 500 套件创建的 GPU 任务
   全部保持 queued（只测排队/取消/优先级），不触发真实训练；真实 GPU 链路只在 E2E 覆盖；
3. **ORM 过期陷阱**：`db.commit()` 后属性过期（expire_on_commit），跨线程/commit 后访问前
   必须捕获纯值（`did, tid = d.id, task.id`）——worker 线程闭包只能捕获纯值；
4. **S3 降级**：`S3_ENDPOINT` 为空时 test_api_storage 整组 skip，500 套件在无 S3 环境仍可全绿；
   S3 启用时 storage 用例走真实 rustfs（写→S3 存在性→删→S3 前缀清空）；
5. **断言宽松于实现细节**：dashboard/summary 只断言键子集（新增字段不破坏旧断言）；
6. **MinerU/vLLM 版本行为**：mineru 4.x 拒绝 .md 文本输入（app.py 直通处理）；
   vLLM 0.15 无 GET /v1/loras（测试仅用 POST load/unload）；未知 model 返 404 非 400；
7. **路由遮蔽**：`GET /api/datasets/tasks` 必须注册在 `GET /{dsid}` 之前（字面量优先）。
