# 训练参数全表（对齐 LLaMA-Factory WebUI）

训练中心超参向导由 **参数 spec 驱动**：`GET /api/training/params` 返回 10 个分组共 **94 个参数**，
前端据此动态渲染表单；后端 `training_service.build_config` 按同一 spec 装配 LLaMA-Factory 配置。

- 参数面与 **LLaMA-Factory 0.9.3**（训练镜像内置版本）的 `ModelArguments / DataArguments /
  FinetuningArguments` + HF `TrainingArguments` 逐一核对过，全部可被 `llamafactory-cli train` 解析；
- **分组显隐**（前后端一致）：`LoRA` 组仅当微调方式=lora；`Freeze` 组仅当微调方式=freeze；
  `DPO` 组仅当阶段=dpo；`导出` 组仅当阶段=export；其余组恒显；
- **未知键透传**：hyperparams 里 spec 之外的键原样写入配置（前向兼容 LF 后续新参数）；
- **extra_args**：JSON 字符串，解析后合并进配置且**优先级最高**（等同 WebUI 的 extra_args 框）；
- 平台内部键（`model_name_or_path`/`stage`/`output_dir`/`dataset` 等）不接受用户覆盖，最终兜底。

## 精度与量化（precision）

| 参数 | 类型 | 默认值 | 说明 |

| `compute_type` | str | bf16 | bf16 / fp16 / fp32 / pure_bf16 → 后端派生 `fp16`/`bf16`/`pure_bf16` 布尔位（fp32=全关） |
